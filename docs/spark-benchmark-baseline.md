## 合成数据与增量正确性

固定生成的 100 只证券、252 个日期数据含 25,200 条有效行情及一条版本修正。
基线与 Shuffle=2 各预热一次、计量一次：Gold 分别为 27.69 和 29.26 秒；
Silver 分别为 26.00 和 26.23 秒。两种配置的输出摘要一致，样本不足以判断性能优劣。
运行资料位于 .cache/benchmarks/smalltest。

合成数据窗口指标和版本去重通过检查。使用 Airflow scheduler 提交 Gold 增量作业，
在隔离表重算 2020-05-01 至 2020-07-31；与全量结果逐行比较，忽略构建时间、
浮点绝对和相对容差各 1e-9，差异 0 行。记录位于
.cache/benchmarks/incremental-check.log 和 incremental-comparison.log。

完整真实数据矩阵使用 suite realbench；运行状态、各项记录及最终汇总见 .cache/benchmarks/realbench。
中规模合成输入使用 bench_medium01，清单见 .cache/benchmarks/input_medium01/prepare。

真实数据完整矩阵的 Gold distribution=none 预热在 2 GiB Executor 堆内存下失败。
堆栈显示 Iceberg FanoutWriter 创建 Parquet 压缩器时发生 Java heap space；
这提示同时打开多个分区写入器可能带来较高内存压力，但还需要控制写入分区布局的
对照才能确认具体原因。失败日志保留在 realbench 对应运行目录，不能纳入成功耗时统计。
