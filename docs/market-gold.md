# 行情筛选与单股研究

`gold_market_cross_section` 是面向页面和 Agent 的每日行情横截面，每行一只证券一个交易日。作业从 Silver 的当前日线全量重建表，保留每个证券日期的最新记录；Spark 的 Iceberg 原子表替换在成功前保留旧表。作业在 `openfinance_market_cross_section` DAG 中工作日 20:30（上海时间）调度；首次使用需运行该 DAG 或手动提交 `spark/jobs/build_market_cross_section.py`；新建表后运行 StarRocks catalog 初始化脚本的 `--grant-only` 为应用用户授予只读权限。全量重建的耗时随历史数据增长，应在启用调度前确认集群容量和 Silver 更新时序。

收益为当日收盘价除以 N 条记录之前的收盘价减一；成交额均值包括当日在内的最近 N 条记录。历史不足或成交额缺失时相应指标为空。Silver 的停牌字段仅用于内部计算过滤，不写入 Gold，也不在行情筛选中展示。缺失的交易日无法从单只股票记录中识别，实际跨度可能更长；当前结果不追溯历史版本，上游修订后历史结果可能变化。

`GET /api/market/gold/screen` 提供日期、指标、排序方向、上下限和数量筛选。`GET /api/market/gold/overview` 组合单股行情、新闻和年报证据。Agent 的 `market_screen` 和 `stock_overview` 使用同一服务。新闻和年报检索为空或不可用时在结果中标明；年报检索需要有效且非空的索引版本。

新增 `ma_5d`、`ma_20d` 为最近 5/20 条记录收盘价均值；`price_ma_5d_deviation`、`price_ma_20d_deviation` 为收盘价除以对应均值减一。`volatility_20d_annualized` 为最近 20 个单日收益的样本标准差乘以 √252，须有 21 条有效价格。`avg_volume_5d` 包含当日，`volume_ratio_5d` 使用当日成交量除以前 5 条记录的平均成交量。窗口不足或缺失时相关指标为空；计算时仍排除 Silver 中明确标记停牌的记录；分母必须为正。`data_status` 仅表示指标字段完整度。停牌状态不属于 Gold 对外字段，缺失交易日也无法由单只股票的行情记录识别。

构建固定 Silver 的当前 Iceberg 快照，在唯一暂存表中构建并校验行数、唯一性、原有业务键和关键字段空值，再检查 Silver 快照是否变化并以 Iceberg 原子替换发布；PostgreSQL 会话锁阻止同一实现的并发构建。日志包含快照 ID、覆盖范围、指标空值及耗时。历史表读取当前已知版本，并不支持按过去时点还原。现有工作日 20:30 调度保留；请确认 Silver 最新交易日和采集状态，作业不会自动补数或断定来源日期已经最新。

隔离验证可使用 `--stage-only` 和独立 `--target-table`；日志给出暂存表名，验证失败及仅暂存时保留该表。正式发布成功后仅清理本次创建的暂存表。上线前应确认输出表的回滚手段和快照保留策略，并在目标环境测量全量构建资源；失败保留旧表。新表字段部署后重新运行 StarRocks 授权初始化并验证在线读取。
